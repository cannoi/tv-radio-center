# TV & Radio Center

An online entertainment center app integrating TV (HLS/M3U8) and Radio (MP3/AAC) streams with curated legal channels, custom channel management, favorites, and a sleep timer.

## Features
- Built-in multimedia player for HLS and audio streams.
- Default legal public channels pre-loaded.
- Quick search and category filtering.
- Add custom channel streams.
- Favorites management.
- Sleep timer functionality.
